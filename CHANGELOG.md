## 1.0.0 — 2026-09-24

Первая версия, перенесённая в репозиторий.

- Сайт на трёх языках (uk / en / ru), группа `PMO-адміністратори`.
- Списки: Проєкти, Статус-звіти, Ризики та проблеми, Зміни показників, Коментарі.
- Ключевые показатели меняются только через статус-отчёт; «Завершено» переводит проект в архив.
- Общее состояние — худшая из трёх оценок (терміни, бюджет, ресурси).
- Оценка риска = вероятность × влияние (1–5 × 1–5).
- Права по иерархии Entra ID, журнал изменений, напоминания PM — `Invoke-PMOSync.ps1`.
- Порядок колонок: стратегический, приоритет, название.
- Вход по сертификату в `Deploy-PMO.ps1` для работы Claude Code и CI; обёртка `Invoke-Env.ps1`.
