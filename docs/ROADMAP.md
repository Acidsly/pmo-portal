## Развитие (кандидаты в задачи разработчика)

| № | Что | Зачем | Заметки |
|---|---|---|---|
| R1 | Язык человека в `nsPrefs` | письма и сповіщення на языке человека | предпосылка для R2 |
| R2 | Недельная рассылка (дайджест) | руководители получают сводку без входа в портал | макеты `docs/digest`, `scripts/PMO.Digest.ps1`; отправитель с `Mail.Send`, ограниченным одним ящиком — настраивает владелец |
| R3 | Портал в Microsoft Teams | вход из привычного места | каталог приложений тенанта — владелец |
| R4 | Помощник ИИ на главной — аналитика портфеля | вопросы по портфелю на естественном языке | развитие пилота `copilot/` |
| R5 | Рекомендации анализа 14.10.2026 | реестр решений с ответственным и сроком; план / прогноз / факт раздельно; последний сигнал PM виден во время погодження | разбить на задачи после R1–R2 |
| R6 | Данные из списков SharePoint в Azure SQL | объём, отчётность, связи | архитектурное изменение: сначала спецификация и план миграции без потери данных, одобрение владельца |
| R7 | Azure Functions вместо runbook PowerShell | API / бэкенд, события вместо расписания | после R6; ресурсы Azure и Key Vault создаёт владелец |
| R8 | Интеграция с хелпдеском | задачи проектов и сроки в одном месте | далёкая перспектива, пакет Service Desk |

Отложено: чат Copilot Studio внутри приложения (05.10.2026, `docs/superpowers/plans/2026-10-05-copilot-chat.md`).

R6–R8 меняют архитектуру и роли доступа (кто администрирует Azure SQL / Functions / Key Vault) — каждая начинается со спецификации в `docs/superpowers/specs/` и решения владельца.
