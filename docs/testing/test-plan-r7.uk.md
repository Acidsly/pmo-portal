# Тестування помічника ШІ у статус-звіті (пілот)

Портал: `https://smarthrua.sharepoint.com/sites/pmo-test` · Версія 1, 14.10.2026 · Версія порталу 1.7.4.1 · **Термін: до середи 21.10.2026** · Інструкція в порталі — кнопка **?** угорі, розділ «Помічник ШІ (пілот)»

## Як проходити тестування

- План — про **помічника ШІ** у формі статус-звіту. Він доступний лише учасникам пілоту; решта користувачів бачить портал як раніше. Попередні плани лишаються чинними.
- Перед початком оновіть сторінку порталу (**Ctrl+F5** / **Cmd+Shift+R**). Угорі «Довідки» (кнопка **?**) має бути **«Версія 1.7.4.1»**.
- Розділи 1–3 — для **PM** (свій проєкт), розділ 4 — для **PMO** (звіт, який PM подав із перевіркою ШІ).
- ШІ — підказка, а не рішення: оцінюйте, **чи допомагає** чернетка й **чи зрозумілі** пункти перевірки. Неточний чи незрозумілий текст ШІ — теж відгук.
- **Усе, що не збігається з планом, фіксуйте відгуком зі скриншотами**: вкладка **Відгуки** → **Залишити відгук** → номер кроку (наприклад, «3.2») → що робили і що побачили.
- Якщо ШІ не відповів, портал сам створить відгук «Помилка ШІ (автоматично)» з технічними даними. Допишіть свій відгук, якщо помилка повторюється.
- Це тестовий сайт: дані демонстраційні, нічого не зламаєте. Кожен виклик ШІ витрачає кредити Copilot Studio: перевіряйте за планом, без масових повторів.

## Що змінилося

| Що | Як працює | Кроки |
|---|---|---|
| Перемикач «Помічник ШІ» | Аватар праворуч угорі → перемикач. Першого разу — згода на обробку даних («Дозволити»), далі — без питань. Вимкнено — форма звіту без ШІ | 1.1–1.5 |
| «Заповнити з ШІ» | Чернетка резюме, «Зроблено», «План», «Проблеми та ризики»; «Що не забути» й пропоновані оцінки — оцінка змінюється лише кнопкою «Прийняти» | 2.1–2.5 |
| «Перевірити з ШІ» | Замість «Зберегти»: суперечності між звітом і даними проєкту. Дати, суми й % порівнює сам портал, зміст — ШІ. Під пунктом про запис реєстру — «Показати запис» і «Додати згадку» | 3.1–3.7 |
| Поле «Суперечності (аналіз ШІ)» | Зберігається у звіті; бачать PM, PMO і всі, хто бачить звіт; на погодження не впливає | 4.1–4.3 |

## 1. Увімкнення (PM)

| № | Що зробити | Що має бути |
|---|---|---|
| 1.1 | Натисніть свій аватар праворуч угорі | Меню під аватаром: ваше ім'я та e-mail, перемикач **«Помічник ШІ»** (вимкнено), підказка «Вимкнено: форма статус-звіту без ШІ». Меню не виходить за край вікна, без горизонтальної прокрутки |
| 1.2 | Увімкніть перемикач | Текст згоди «Помічник ШІ надішле дані цього звіту й проєкту в Microsoft Copilot Studio…» і кнопки «Дозволити» / «Скасувати»; перемикач ще вимкнений |
| 1.3 | «Скасувати» → знову увімкніть → «Дозволити» | Після «Скасувати» — вимкнено. Після «Дозволити» — «Підключення…», за кілька секунд перемикач увімкнено, підказка «Увімкнено: у формі статус-звіту — «Заповнити з ШІ» і «Перевірити з ШІ». Може на мить з'явитися вікно входу Microsoft — воно закриється саме |
| 1.4 | «Новий статус-звіт» свого проєкту | Угорі форми — **«Заповнити з ШІ»** (фіолетовий контур, значок іскор), унизу замість «Зберегти» — **«Перевірити з ШІ»** у такому самому стилі; висота кнопок однакова зі «Скасувати». Згоду у формі не питає |
| 1.5 | Закрийте форму → аватар → вимкніть перемикач → відкрийте форму знову; потім увімкніть ще раз | Вимкнено — форма як раніше («Зберегти», без кнопок ШІ). Повторне ввімкнення — одразу, без тексту згоди |

## 2. Чернетка — «Заповнити з ШІ» (PM)

| № | Що зробити | Що має бути |
|---|---|---|
| 2.1 | Новий звіт, тексти порожні → **«Заповнити з ШІ»** | «ШІ готує чернетку…» (кнопку не натиснути вдруге, «Скасувати» — скасувати запит); за 3–7 секунд заповнені «Резюме», «Зроблено за період», «План на наступний період», «Проблеми та ризики за період»; повідомлення «Чернетку ШІ вставлено — перевірте й виправте тексти» |
| 2.2 | Подивіться панель **«Підказки ШІ»** над формою | «Що не забути» — пункти минулого плану без результату, прострочені заходи, високі ризики, запит рішення (якщо є); «ШІ пропонує оцінки» з причиною. Оцінки у формі **не змінилися**. Панель згортається |
| 2.3 | Натисніть **«Прийняти»** біля однієї оцінки | Ця оцінка стала такою, як пропонує ШІ; інші — без змін |
| 2.4 | **«Скасувати вставку ШІ»** | Тексти — як до вставки. Змініть текст і знову «Заповнити з ШІ»: для заповненого поля — питання «Замінити текст у полі «…» чернеткою ШІ?» («Замінити» / «Залишити мій») |
| 2.5 | Перемкніть мову на **EN** → «Заповнити з ШІ» | Тексти чернетки й підказки — англійською |

Оцініть: чи можна взяти чернетку за основу звіту, що в ній зайве або неправильне, — відгуком із кроком «2.1».

## 3. Перевірка — «Перевірити з ШІ» (PM)

| № | Що зробити | Що має бути |
|---|---|---|
| 3.1 | Новий звіт без оцінок і резюме → «Перевірити з ШІ» | Звичайні помилки біля полів; ШІ не викликається |
| 3.2 | Заповніть звіт без суперечностей (оцінки відповідають показникам, ризики згадані з діями) → «Перевірити з ШІ» | «ШІ аналізує…», за 2–4 секунди — «Суперечностей не знайдено — можна зберегти»; кнопка — синя **«Зберегти»** |
| 3.3 | «Терміни» — зелений, «Прогноз завершення» пізніше «Дата завершення (план)» → «Перевірити з ШІ» | Поле **«Суперечності (аналіз ШІ)»** (лише для читання), перший пункт — «Терміни» — зелений, а «Прогноз завершення» … пізніше … — змініть оцінку «Терміни» або «Прогноз завершення»» |
| 3.4 | У проєкті є відкритий високий ризик (оцінка від 15) або проблема, а в «Проблеми та ризики за період» його немає → перевірка | Пункт про цей запис реєстру з назвою, оцінкою й терміном; під ним — **«Показати запис «…»»**: картка запису, **«Додати згадку»** — рядок із заходами додано в кінець «Проблеми та ризики за період» |
| 3.5 | Змініть будь-яке поле звіту | Кнопка знову **«Перевірити з ШІ»**; повторна перевірка не повторює виправлені пункти |
| 3.6 | Лишіть пункт невиправленим → «Зберегти» | Звіт збережено разом із результатом перевірки — погоджуватися з ШІ не обов'язково |
| 3.7 | Мова **EN** → перевірка звіту з кроку 3.3 | Пункти — англійською (і пункт порталу, і пункти ШІ) |

Оцініть: чи зрозуміло з кожного пункту, **що й де виправити**; чи немає хибних пунктів — відгуком із кроком «3.х» і текстом пункту.

## 4. Перегляд і погодження (PMO)

| № | Що зробити | Що має бути |
|---|---|---|
| 4.1 | Відкрийте звіт, поданий PM із перевіркою ШІ (крок 3.6) | Блок **«Суперечності (аналіз ШІ)»** із пунктами й «Перевірено ШІ: дата час» |
| 4.2 | Погодьте або поверніть звіт, як зазвичай | Блок ШІ на погодження не впливає; рішення PMO — як раніше |
| 4.3 | Відкрийте старий звіт (до 14.10) або звіт PM поза пілотом | Блоку ШІ немає |
