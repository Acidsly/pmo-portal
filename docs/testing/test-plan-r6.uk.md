Сповіщення й «Історія змін» оновлюються автоматично протягом ~15 хвилин.

## 1. Новий ризик або проблема (PM)

| № | Що зробити | Що має бути |
|---|---|---|
| 1.1 | Свій проєкт → «Додати ризик / проблему» | Біля «Опис», «Стратегія реагування», «Заходи для зниження ризику», «План дій у разі настання» — **\***; під формою — «Ризики й проблеми не погоджуються: … PMO бачить у сповіщеннях; зворотний зв'язок — коментарем у картці проєкту» |
| 1.2 | Нічого не заповнюючи — «Зберегти» | Біля кожного з чотирьох полів — пояснення («Опишіть ризик або проблему.», «Оберіть стратегію реагування.», «Опишіть заходи.», «Опишіть план дій у разі настання.»); унизу — «Заповніть обов'язкові поля (\*)»; запис не створюється |
| 1.3 | Оберіть тип **«Проблема»** | Зірочки лишаються лише біля «Опис» і «Заходи…»; без стратегії й плану дій проблема зберігається |
| 1.4 | Ризик з низькою оцінкою (наприклад, 1 × 2) і лише пробілами в «Заходи» → «Зберегти» | Помилка біля «Заходи…» — обов'язкові поля не залежать від оцінки; пробіли не вважаються заповненням |
| 1.5 | Заповніть усі поля, термін — сьогодні або пізніше → «Зберегти» | Запис збережено, він у блоці «Ризики та проблеми» картки |

## 2. Збережений запис і копія (PM)

| № | Що зробити | Що має бути |
|---|---|---|
| 2.1 | Відкрийте збережений ризик (з кроку 1.5 або будь-який свій) | Угорі — «У збереженому записі змінюється лише «Статус»…»; доступне лише поле **«Статус»**, решта — тільки для перегляду; внизу — **«Копіювати ризик»** («Копіювати проблему» — для проблеми) |
| 2.2 | Змініть статус на «В роботі» → «Зберегти» | Збережено; через ~15 хвилин в «Історії змін» картки — «Статус Відкрито → В роботі» |
| 2.3 | Відкрийте той самий ризик → **«Копіювати ризик»** | Форма «Новий ризик» з усіма полями вихідного запису, статус «Відкрито», угорі — «Копія запису «…»: … Вихідний запис закрийте окремо». Змініть, наприклад, заходи → «Зберегти»: у блоці — **два** записи. Відкрийте вихідний → статус «Закрито» → «Зберегти» |
| 2.4 | Відкрийте запис із **простроченим** терміном (статус не «Закрито») | Під терміном — «Термін минув — закрийте запис або створіть копію з новим терміном»; у копії термін порожній — вкажіть новий (не раніше сьогодні) |
| 2.5 | Старий запис без стратегії чи заходів (створений до 1.7.3.1) → змініть лише статус | Зберігається: обов'язкові поля перевіряються лише для нового запису й копії |
