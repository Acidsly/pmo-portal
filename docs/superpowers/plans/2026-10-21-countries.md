## Риски

- Ключевое поле: правка `pmCountry` не через «Призначення» откатывается — поэтому форма правки его не пишет (иначе ложные откаты).
- Архив заморожен: CEO на архивных проектах появится только при `rebuild-permissions` (воскресенье 3:00) — приемлемо.
- Таблица: колонка вне `defaults` у людей с сохранённым набором колонок появится через «Поля та порядок»; в `defaults` добавляем с новым ключом состояния таблицы, только если пользователь хочет её видеть у всех сразу.
- E-mail CEO не попадают в git (`config/countries.json` в `.gitignore`).
- Внешние учётные записи (`#EXT#`): синхронизация выдаёт права по `membership|<e-mail>` — CEO только с внутренней учётной записью тенанта; проверка `whois` до выкладки.
- Колонка «Країна» не в `defaults` таблицы (появляется через «Поля та порядок»), если пользователь не решит иначе на воротах.
- Ревью плана — Sonnet 21.10: approve with changes, HIGH-1…4 и MEDIUM-5…9 внесены выше.
