# Батьківський проєкт — план

Запрос 19.10.2026: «Маркер родительского проекта — можно выбрать проект, который будет родительским. Пока только для связки, дальше — аналитика». Признак «Впровадження / Супровід» — отменён («отбой»).

## Решения (приняты 19.10.2026)

- Поле «Батьківський проєкт» в карточке проекта: задаёт PMO при создании, PM меняет при правке карточки; изменение — в «Історії змін» (как остальные правки карточки, через `pmEditLog` → журнал синхронизацией). Не ключевой показатель (не через отчёт, не в эталоне).
- Ограничения: **только «не сам себя»**; вложенность — любая; архивные проекты выбирать можно. Дополнительно (сказано пользователю): нельзя выбрать свой дочерний проект на любой глубине — иначе цикл «проект — родитель самому себе через цепочку».
- Показ: в карточке — «Батьківський проєкт» ссылкой и блок «Дочірні проєкти»; в «Проєкти» — колонка «Батьківський проєкт» с фильтром (не в колонках по умолчанию). Нет доступа к родителю — название без ссылки; дочерние — только видимые человеку.
- Права связь не даёт (ни родителю, ни дочерним).

## Модель

- SharePoint: `Lists/Projects`, поле `pmParent` — Lookup на «Проєкти» (ShowField Title, не обязательное, индексированное, удаление родителя — `RelationshipDeleteBehavior='None'`: проекты не удаляются, но ссылка не должна мешать). `Deploy-PMO.ps1`, функция `F` (идемпотентно). Порядок выкладки: `deploy` → `app` (приложение запрашивает поле).
- Приложение: `Project.parent: { id, title } | null` (`pmParentId`, `pmParent/Title` — название видно и без доступа к родителю); `ProjectDraft.parentId: number` (0 — нет); запись `pmParentId` (null — снять).
- Журнал: `cardDiff` — `parent` (название было → стало); синхронизация: ключ `parent` → `pmParent`, подпись «Батьківський проєкт»; `logic/changes.ts`: `pmParent` → `parent`; FLD `parent` в прототипе (uk / en / ru).
- Правило выбора — чистая функция `parentChoices(projects, selfId)` в `logic/projects.ts`: все проекты, кроме себя и своих потомков (по цепочке родителей, защита от уже существующих циклов в данных); общие векторы `tests/cases/parent.json` — их прогоняют Jest (`logic`) и прототип (jsdom). `childrenOf(projects, id)` — прямые дочерние.
