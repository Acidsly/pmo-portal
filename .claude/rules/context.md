# Контекст проекта, которого нет в коде

- **Тенант:** `smarthrua` (https://smarthrua.sharepoint.com). Прод — `/sites/ppm` (с 20.10.2026, выпуск 1.7.5.2), тест — `/sites/pmo-test` (фокус-группа: PMO и несколько PM; роли — `config/focus-group.json` вне git).
- **Владелец сайтов и проекта:** j.pochobut@eclectic.group. Репозиторий: `git@github.com:Acidsly/pmo-portal.git` (SSH).
- **Синхронизация:** Azure Automation `aa-pmo-sync` (`rg-pmo-automation`), runbook `PMO-Sync` — прод, `PMO-Sync-Test` — тест; каждые 15 минут. Напоминания письмом пока не нужны (без `Mail.Send` у тестовых приложений).
- **Вход в Microsoft 365** для скриптов, которым нужен браузер, — в том браузере, где выполнен вход корпоративной учётной записью; если открывается не тот — `-DeviceLogin` и открыть код вручную.
- **Письма коллегам** (фокус-группа, PMO, PM) — только с корпоративного ящика домена eclectic.group (Outlook), не из личной почты; сначала черновик → показать текст → «да» → отправка. Адреса — из пользователей сайта / Entra ID.
- **Отложено:** чат Copilot Studio внутри приложения (решение 05.10.2026, план `docs/superpowers/plans/2026-10-05-copilot-chat.md`); в будущем — пакет Service Desk (хелпдеск, PPM, договоры, заявки на расходы) с единой точкой входа. Помощник ИИ статус-отчёта (пилот) — работает, `copilot/`.
- **Где сейчас проект и что дальше:** [docs/ROADMAP.md](../../docs/ROADMAP.md).
